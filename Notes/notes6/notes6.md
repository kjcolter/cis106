# Notes 6 
## mkdir

\- Definition

- `mkdir` is used to create new directories (folders).

\- Usage

- `mkdir` is used when you want to organize files by creating folders.

\- Formula

- `mkdir + directory_name`

\- Examples

- Create a directory named website:
  - `mkdir website`
- Create a directory with a subdirectory:
  - `mkdir -p website/assets`

## touch

\- Definition

- `touch` is used to create an empty file or update the timestamp of an existing file.

\- Usage

- `touch` is used when you need to create a new empty file.

\- Formula

- `touch + file_name`

\- Examples

- Create a text file:
  - `touch notes.txt`
- Create an HTML file:
  - `touch index.html`

## rm

\- Definition

- `rm` is used to remove files and directories.

\- Usage

- `rm` is used when you want to delete unwanted files or folders.

\- Formula

- `rm + file_name`

\- Examples

- Delete a text file:
  - `rm notes.txt`
- Delete a directory and its contents:
  - `rm -r website`

## cp

\- Definition

- `cp` is used to copy files and directories from one location to another.

\- Usage

- `cp` is used when you want to make a duplicate of a file or folder.

\- Formula

- `cp + source + destination`

\- Examples

- Copy a text file:
  - `cp notes.txt backup.txt`
- Copy an image into the Pictures folder:
  - `cp image.jpg ~/Pictures/`

## mv

\- Definition

- `mv` is used to move or rename files and directories.

\- Usage

- `mv` is used when you want to change a file's location or name.

\- Formula

- `mv + source + destination`

\- Examples

- Move a text file into Documents:
  - `mv notes.txt Documents/`
- Rename a file:
  - `mv oldname.txt newname.txt`
