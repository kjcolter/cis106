 # Lecture 2 Introduction to Linux Notes

 ## What is an Operating System?

 An operating system is software that manages a computer’s hardware and software and allows users and applications to interact with the computer.

 ## What is a kernel?

 A kernel is the core part of an operating system that manages hardware resources such as the CPU, memory, and storage.

 ## Which other parts aside from the kernel identify an OS?

 The other parts include the shell, system utilities, system libraries, desktop environment, and applications.

 ## What is Linux?

 Linux is a free and open-source operating system kernel. It is also commonly used to refer to operating systems built around the Linux kernel.

 ## What is a Linux distribution?

 A Linux distribution is a complete operating system based on the Linux kernel that includes system utilities, libraries, applications, and other software.

 ## List at least 4 Linux characteristics:

 - Open source
- Free to use
- Multiuser
- Multitasking
- Secure
- Portable

 ## What is Debian?

 Debian is a free and open-source Linux distribution known for its stability, large software repository, and package management system.

 ## List and define the different types of licensing agreements

 - **Proprietary License:** Restricts how software can be used, copied, modified, or distributed.
- **Open-Source License:** Allows users to use, view, modify, and distribute software according to the license terms.
- **Permissive License:** An open-source license with few restrictions on using and redistributing software.
- **Copyleft License:** Allows modification and distribution but generally requires modified versions to use the same or a compatible license.
- **Public Domain:** Software that is not protected by copyright restrictions and can generally be used freely.
- **Shareware/Trial License:** Software provided for evaluation, usually with limitations or for a limited amount of time.

 ## What is Free Software? Define the 4 freedoms.

 Free Software is software that gives users the freedom to use, study, modify, and share the software.

 1. **Freedom 0:** The freedom to run the program for any purpose.
1. **Freedom 1:** The freedom to study how the program works and modify it.
2. **Freedom 2:** The freedom to redistribute copies of the program.
3. **Freedom 3:** The freedom to distribute modified versions of the program.

 ## What is virtualization?

 Virtualization is a technology that allows one physical computer to run multiple virtual computers, called virtual machines (VMs), each with its own operating system and applications.
